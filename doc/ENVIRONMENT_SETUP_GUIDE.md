# Environment setup guide

Use this index to find the installation instructions for all seven projects. Follow each project's linked instructions in its own Conda environment, including its Python, PyTorch, CUDA, and compiled-extension requirements.

This is a guide to the upstream setup documentation, not an export of the environments previously installed on this machine. The links point to GitHub so they can be used from any machine.

| Project | Where to look | What to follow |
| --- | --- | --- |
| **Articulat3D** | [README → Installation](https://github.com/ShawnRicardo/Articulat3D#installation) | Follow **Installing dependencies**, including the TAPIP3D requirements and the pointops2 / pointnet_lib compilation steps. The documented Conda environment is `articulat3d`. MegaSAM is an optional additional build for the monocular-video workflow described there. |
| **Depth Anything 3** | [README → Installation](https://github.com/ByteDance-Seed/Depth-Anything-3#-installation) | Follow the basic package installation and select the optional Gaussian-head, app, or all-dependencies installation as needed. The upstream section provides pip commands; create and activate a dedicated Conda environment first. For streaming, also consult the [DA3-Streaming README](https://github.com/ByteDance-Seed/Depth-Anything-3/blob/main/da3_streaming/README.md). |
| **HaWoR** | [README → Installation](https://github.com/ThunderVVV/HaWoR#installation) | Follow the recursive clone, `hawor` environment setup, and **Install masked DROID-SLAM** steps. Continue through the Metric3D, model-weight, and MANO instructions to prepare the assets needed to run it. |
| **TrackCraft3R** | [README → 1. Environment](https://github.com/cvlab-kaist/TrackCraft3r#1-environment) | Follow the `trackcraft3r` Conda setup, package installation, and Accelerate configuration. For processing your own videos, consult [6. Run on your own video](https://github.com/cvlab-kaist/TrackCraft3r#6-run-on-your-own-video), which describes separate depth/camera preprocessing environments. |
| **SegviGen** | [README → Installation](https://github.com/Nelipot-Lee/SegviGen#-installation) | Start by creating the **TRELLIS.2** environment using the setup command specified by SegviGen, then install SegviGen's additional dependencies in that environment. See the [TRELLIS.2 installation instructions](https://github.com/microsoft/TRELLIS.2#%EF%B8%8F-installation) and [setup script](https://github.com/microsoft/TRELLIS.2/blob/main/setup.sh) for the underlying environment setup (`trellis2` by default). |
| **SAM 3** | [README → Installation](https://github.com/facebookresearch/sam3#installation) | Follow the prerequisites, `sam3` Conda setup, PyTorch installation, and editable package installation. Choose notebook, training/development, and inference extras as needed. See [Getting Started](https://github.com/facebookresearch/sam3#getting-started) for checkpoint access and authentication. |
| **SAM 3D Objects** | [Setup guide](https://github.com/facebookresearch/sam-3d-objects/blob/main/doc/setup.md) | Follow **1. Setup Python Environment**, starting with the [default environment YAML](https://github.com/facebookresearch/sam-3d-objects/blob/main/environments/default.yml), then the staged dependency installs and Hydra patch. The environment is `sam3d-objects`; the guide explains using Conda in place of Mamba. Continue to **2. Getting Checkpoints** for model access and downloads. |

Complete the checkpoint/model-download instructions as well as the package installation before running a project. Use the versions specified by each project's documentation rather than assuming one shared environment will work for all seven.
